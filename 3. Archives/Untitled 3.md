&gt;Goal:
Run a full-stack automated innovation pipeline that discovers, evaluates, evolves, and fuses cross-industry ideas into commercial MVP specs — tailored for the [Target Industry].
&gt;Pipeline Structure:
&gt;────────────────────
&gt;PHASE 1 — Discovery
&gt;1. Search for high-engagement products or systems from other industries (fitness, gaming, microlearning, crowdfunding, behavioral finance).
&gt;2. Analyze what makes them succeed (habit loops, reward systems, community dynamics, or progress incentives).
&gt;3. Translate top 5 mechanics into potential [Industry] SaaS use cases.
&gt;Output → list of 5 opportunity seeds.
&gt;────────────────────
&gt;PHASE 2 — MVP Generation &amp; Ranking
&gt;1. Turn each opportunity seed into a concise MVP concept brief:
&gt;   - Name, Hook, Problem Solved, Core Mechanic, SME Segment, Monetization Model, API Hook Summary.
&gt;2. Score each with:
&gt;   - Market Impact (×0.5)
&gt;   - Simplicity (×0.3)
&gt;   - Novelty (×0.2)
&gt;3. Rank using a calculated “Viability Score (0–100)” and generate an MVP Ranking Table.

&gt;Output → ranked list of MVPs (top 3 move forward).

&gt;────────────────────
&gt;PHASE 3 — Gradient Evolution Loop
&gt;1. Take the top MVP and produce 3–5 micro‑pivots altering only one variable (target persona, UX narrative, monetization lever, or feature focus).
&gt;2. Rescore each for resonance, simplicity, and market leverage.
&gt;3. Keep the two best variants as “Evolution Pair.”

&gt;Output → best two evolved variants, each refined from MVP winner.

&gt;────────────────────
&gt;PHASE 4 — Hybrid Fusion
&gt;1. Compare Attribute‑by‑Attribute between the two variants (mechanic, UX, model, market).
&gt;2. Merge their strongest traits into a single hybrid MVP concept.
&gt;3. Evaluate hybrid across:
&gt;   - Combined Market Potential
&gt;   - Integration Complexity
&gt;   - Strategic Differentiation vs. Parents.

&gt;Output → Hybrid MVP Concept Sheet (name, one‑line pitch, key features, build plan, KPIs).

&gt;────────────────────
&gt;PHASE 5 — Final Spec Output
&gt;1. Present a complete MVP Specification Document ready for prototype planning.
&gt;2. Include:
&gt;   - Elevator Pitch
&gt;   - Core Mechanics Summary
&gt;   - Initial UX Feature Set
&gt;   - MVP Build Plan ([Popular Vibe Coding Tech Stack] integration path)
&gt;   - Suggested KPIs (engagement rate, completion quality, retention frequency)
&gt;   - Monetization or certification angle
&gt;3. Generate a “Next Cycle” seed prompt so the process can auto‑restart, improving on last output.

&gt;Output Format:
&gt;──────────────
&gt;Full Pipeline Summary:
&gt;- Discovery Seeds
&gt;- MVP Ranking Table
&gt;- Evolution Pair Summary
&gt;- Hybrid MVP Sheet
&gt;- Final Spec Blueprint
&gt;- Next‑Cycle Seed Prompt

&gt;Operational Mode:
Run sequentially. Each stage builds logically on the last. Preserve reasoning traces between outputs. Auto‑summarize findings at every phase.
